CASE STUDY: KUBERNETES PLATFORM

GitOps-based Kubernetes Deployment Pipeline

Problem

Manual cluster updates were leading to configuration drift, untracked changes, and unreliable rollback capabilities across dev, staging, and prod environments.

Investigation & Solution

Designed a GitOps workflow using ArgoCD to continuously sync Kubernetes manifests directly from a Git repository, establishing Git as the single source of truth.

Outcome & Lessons

Environment-based manifest layout with scripted image tagging now triggers auto-deployments. Cluster state always matches declared code—resulting in instant rollback capabilities, zero manual drift, and a full audit trail of every deploy.

RAG-based Document Q&A System

Problem: Needed an automated way to query dense, natural-language PDF documents accurately without hallucination.

Solution: Built a modular RAG pipeline utilizing LangChain, chunking overlapping PDF segments, and generating vector embeddings.

Outcome: A fast, semantic similarity search system integrated with an LLM that grounds user queries accurately in the uploaded documents.
